Galaxy XR OTA Control - KernelSU module for the Samsung Galaxy XR (SM-I610).

Author: 4uva4ek.

This package contains no vendor, third-party or native code. Every file is
authored here as POSIX shell and plain text, so it carries no NATIVE-NOTICE or
NDK notice. It is not built with an NDK toolchain and contains no ELF payload.

Package contents:
  module.prop    module metadata and update feed
  service.sh     boot stage entry point
  ota-ctl.sh     block, restore, status and boot logic
  action.sh      KernelSU Action button report and explicit on/off commands
  uninstall.sh   restore on removal
  customize.sh   refuses the generic installer path
  NOTICE.txt     this file
  disable        empty marker: the package installs disabled
  SHA256SUMS     checksums of every other file except the marker

The module changes Android package enabled state and one global setting only.
It never writes system partitions, APKs, libraries or KernelSU startup files.
