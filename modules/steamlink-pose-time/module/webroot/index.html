Steam Link Pose Time

Limits: 0.00 – 30.00 ms. Default: 15 ms.
28.82 ms = original label delay: the runtime labels every controller slot 28.82 ms ahead of the pose it carries (measured 2026-10-12). This value sends the true content epoch.
0 ms = raw slot label, the 0.1.3 behaviour (steadier, but the PC extrapolates ~29 ms less and the controllers lag).
Smaller value = shorter PC horizon, steadier but later. Larger value = longer horizon, fresher but more jerk on acceleration.
Applied live within about 2 seconds while the module is enabled and attached to Steam Link; otherwise used at the next activation. Saving does not enable the module.
