# Haptic MAIN 0.2.0

Модуль KernelSU для Galaxy XR SM-I610: обычная вибрация OpenXR перенаправляется
с SUB у триггера на MAIN в рукоятке. Проверено пользователем на обоих контроллерах
в Steam Link 2.0.20 без HAL-слоёв 10 октября 2026 года.

**Action** переключает MAIN ↔ STOCK. Автозапуска и фонового процесса нет.
Полная перезагрузка или перезапуск службы возвращает STOCK; для MAIN нужно снова
нажать Action. Галочка отключения модуля не откатывает уже изменённую память:
перед удалением выполните `off` или перезагрузите шлем.

```sh
su -c 'sh /data/adb/modules/gxr_haptic_main/action.sh status'
su -c 'sh /data/adb/modules/gxr_haptic_main/action.sh on'
su -c 'sh /data/adb/modules/gxr_haptic_main/action.sh off'
```

Лог: `/dev/gxr_haptic_main/log` (tmpfs). При ошибке отключения полная перезагрузка
возвращает оригинальный код. Перезагрузка в проверочном сеансе не выполнялась;
программный откат через Action проверен.

## Механизм

Переключатель останавливает потоки `com.sec.android.secxrcontrollerservice`,
проверяет функцию и заменяет одну ARM64-инструкцию в её приватном отображении
через ptrace. Затем немедленно отсоединяется. Возможна краткая пауза отслеживания
при переключении. APK и системная библиотека на диске не изменяются.

В `nativePerformHapticFeedback` по смещению `0x1238c`:

```text
STOCK: 62 01 00 94    bl 0x12914      ; JNI CallIntMethod: Vibrator.ordinal()
MAIN:  20 00 80 52    mov w0, #1      ; MAIN
```

Сохраняются амплитуда, частота, длительность, PCM и остановка вибрации.
Штатная служба продолжает пользоваться своим HAL. Собственного HAL-клиента,
Frida или Shizuku у модуля нет. Прямые HAL-вызовы сторонних приложений он не меняет;
другие клиенты той же JNI-функции тоже попадут под перенаправление.

## Совместимость

Поддерживается только точная пара SHA-256:

| Оригинал | SHA-256 |
| --- | --- |
| `/product/priv-app/secxrcontroller/secxrcontroller.apk` | `8130b5542c36235eb1e951b9245684299d6a7ddd1a8c95f231e8241e477673cb` |
| `/system/lib64/libsecxrcontrollerservice_jni.xrcontroller.samsung.so` | `80d45131558b28107cf7e3c9a2c483bce4e2207b934e4f25e951f0fc79d1cd36` |

Также проверяются процесс, приватность отображения, 1640 байт функции и текущее
значение инструкции. Неизвестная прошивка или стороннее изменение вызывают отказ.
`native/expected.h` содержит эталон инструкции/функции для этой проверки.

## Установка

ZIP имеет формат модуля KernelSU. Перед использованием штатного установщика
проверьте его поведение в вашей сборке KernelSU. В проверенной Samsung-сборке
`ksud module install` дополнительно переписывает `/metadata/.../modules.rc`,
поэтому мы установили файлы прямо в новый каталог
`/data/adb/modules/gxr_haptic_main`, без запуска установщика и изменения загрузочных
файлов. Произвольные обновления KernelSU и прошивки не проверены.

Сборка из корня репозитория: `python tools/build.py haptic-main --ndk PATH`.
Результаты проверки и ограничения — в [журнале](../../docs/VALIDATION-2026-10-10.md).
