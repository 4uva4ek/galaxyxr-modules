# Haptic MAIN 0.2.0 — проверка 10 октября 2026

Устройство: Samsung Galaxy XR SM-I610, Android 14/API 34, временный root KernelSU.
Оригиналы и точные SHA-256 указаны в README модуля.

- MAIN → STOCK → MAIN через штатный Action KernelSU: успешно.
- Пользователь подтвердил вибрацию в рукоятках обоих контроллеров в Steam Link
  2.0.20 с удалёнными HAL pose/haptics и их мостами.
- Служба контроллеров не перезапускалась; после переключения TracerPid=0.
- Хеши системной библиотеки и APK не изменились. SELinux остался Enforcing.
- Нет startup-скриптов, rc, system.prop, sepolicy.rule, mount-замен или демона.
- Проверены ZIP, хеши каждого файла, ARM64 ELF, shell-синтаксис и отказ
  от упаковки посторонних компонентов.

Полная перезагрузка в этом сеансе не выполнялась. Возврат штатного кода после неё
основан на изменении только приватной памяти и отсутствии повторного применения
при загрузке. Длительная игровая стабильность и другие прошивки не подтверждены.

Предыдущая попытка 0.1.0 с Frida завершалась транспортной ошибкой до выполнения JS.
Точный системный отказ не установлен. Версия 0.2.0 полностью устраняет Frida,
а не ослабляет SELinux для запуска агента. Материалы 0.1.0 в этот репозиторий
не включены.
