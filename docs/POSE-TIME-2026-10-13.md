# Steam Link Pose Time release validation

Author: **4uva4ek**. Version 0.1.2.

The correction payload is byte-identical to the user-approved full-epoch RAM
experiment and installed-disabled 0.1.1 (SHA-256
`f6dfddb0193559bd488eb3ab739674caf9a1eba7d9724adfd78e6cf1f9ee313c`).
No new motion algorithm or synthetic motion suite was introduced for publication.

The earlier manual experiment verified three app-private GOT hooks, both hands,
actual wire offsets and PC reception. Manual restoration and process-exit removal
were verified. The first inactive-app allocation attempt timed out cleanly;
register restoration and detached threads were verified before active-app retry.
The 0.1.1 installed-disabled service/worker, checksum, native selftest and Action
checks passed without enabling the module or changing other module preferences.

Release checks cover clean-source NDK build, exact payload equivalence,
package paths/disabled state/checksums, source layout, feed validation and the
Manager off/status contract (including stale-log, live-worker and error cases).
No vendor dump, generated compatibility header or device receipt is published.

The 30-second full-epoch capture had 10,800 packets, no logger drops and valid
controller motion. Wire offset median ~24.2ms and PC offset ~39.4ms demonstrate
forwarding, not physical sensor accuracy. Rare unmodified timing fields remain;
large API backsteps were observed near some such packets. The user nevertheless
approved the current behavior. This release preserves that exact behavior.

Enabled automatic app-relaunch and soft/cold reboot were not exercised for this
release. Native throwing, physical latency and rendered-frame prediction remain
unvalidated. Installation and publication do not authorize enablement or reboot.
