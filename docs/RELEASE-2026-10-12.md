# Public module updates, 2026-10-12

All five previously downloadable modules were rebuilt from clean source commit
`930fac25c329d36b6eb30a4285190a316fc28efe`, with Android NDK 28.2.13676358. Only
disabled automatic ZIPs and their SHA-256 sidecars were published. Experimental
modules and proprietary runtime/compositor payloads were excluded.

| Module | Version | Change from previous public package |
| --- | --- | --- |
| Haptics MAIN | 0.5.6 | Stable update feed metadata |
| Controller Extrapolation | 0.4.3 | Stable update feed metadata |
| OpenXR Velocity Frame | 0.3.5 | App-exit/PID lifecycle fixes from local 0.3.4, plus feed metadata |
| Controller Whitening | 0.1.4 | Stable update feed metadata |
| Controller Timestamp Precision | 0.1.3 | Stable update feed metadata |

For the four metadata-only releases, the complete packaged runtime scripts and
native binaries are byte-identical to the prior public packages. Only
`module.prop` and its checksum manifest changed. Velocity's native helper is
byte-identical to the previously built/read-only-tested local 0.3.4 helper
(`d8a704414ed341aabf009cfa910c57cdd50d604315fe460d053b7773c9fe3cb0`).
See [Velocity lifecycle evidence](VELOCITY-LIFECYCLE-2026-10-12.md).

## Validation

- Five strict ARM64 builds and package contents/checksum/provenance checks passed.
- Shared host tests: restart lifecycle 12, process identity 1, autostart 13,
  cold-boot reset 12, standard controls 3, haptic readiness 5, update feeds 3.
- Whitening's 12 and Timestamp Precision's 11 lifecycle tests passed.
- Extrapolation's Windows/Git-Bash worker-timeout restoration test passed. Its
  initial invocation on Linux failed because the existing test hardcodes Bash's
  Windows path; rerunning on its intended host resolved the test-environment issue.
- Six bounded package-discovery scenarios passed, including timeout and failure.
- Velocity: 6,000 C++ math cases, 100 origin identities, 1,728 ARM64 prediction
  cases, 10,096 corrupted-byte rejections and independent restoration checks passed.
- The new GXR updater accepted all five exact release archives in its host test.
- GitHub's promotion job validated each published ZIP and advanced its independent
  stable feed. Downloaded release bytes and source tag commits were checked against
  the local release manifest; every tag points to the clean source commit above.

No module was installed, enabled or restarted on the headset for this publication.
Live update through the new Manager and Velocity's enabled app-exit/relaunch
behavior remain unvalidated on-device. Native throwing and physical improvement
are not established by these tests. Previous validation of unchanged native code
does not establish correctness on unreviewed firmware.

Install using [the reviewed Manager workflow](INSTALLING-MODULES.md). A replacement
stays disabled and preserves failure guards. Enabling it and performing any
soft restart are separate deliberate actions.
